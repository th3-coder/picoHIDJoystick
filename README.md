"# picoHIDJoystick" 

Raspberry Pi Pico (1-2) joystick with button project

1. HOLD RESET BUTTON AND PLUG IN Pico

2. WAIT FOR PICO TO RESET AND COME BACK AS A STORAGE DEVICE
    A. DRAG THE U2 CIRCUIT PYTHON BOOTLOADER INTO THE STORAGE DEVICE AND ALLOW TO RESET

3. COPY ALL ENTIRE LIB DIRECTORY AND main.py file (v1 or v2) directly on to pico storage device

4. Either 
* run code directly from choice of ide (thonny preferably) or 
    
* unplug and plug back in
 

 *** main.py will looped and interpreted everytime the pico device is plugged in ***
